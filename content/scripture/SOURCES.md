# Scripture sources

## Starter verse set (`android/app/src/main/assets/scripture/verses.json`)

- **Translation:** World English Bible (WEB), public domain. The WEB preface states it may be freely copied, distributed and redistributed; the name "World English Bible" is reserved for faithful copies of the text.
- **Downloaded from:** https://ebible.org/Scriptures/eng-web_usfm.zip on 2026-10-28.
- **How the text was produced:** a script read the USFM files and extracted each listed verse, stripping footnotes and word-tagging markup. Nothing was typed from memory. Verse text is unedited WEB.
- **Note:** this edition writes God's name in the Old Testament as "Yahweh" (for example Psalm 32:5, Lamentations 3:22, Isaiah 40:31).
- **Status:** placeholder until the ESV licence question (D-001) is answered. The product owner reviews the verse choices.
